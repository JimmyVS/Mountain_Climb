> **Scale mountains in VR using realistic hand-over-hand climbing mechanics. Built with Unity and the XR Interaction Toolkit.**

---

## 🧠 Features

- 🧗‍♂️ **Immersive Climbing** – Grab ledges, rocks, and climbable holds to traverse vertical environments.
- 🎮 **VR Hand Tracking** – Supports Oculus, OpenXR, and other XR devices.
- 🌄 **Realistic Physics** – Feel the weight and momentum of your movements.
- 🚧 **Dynamic Challenges** – Moving grips, crumbling rocks, and timed jumps.
- 📊 **Height Tracking** – Tracks your climb progress, distance, and time.
- 🔉 **Sound & Haptic Feedback** – Feel every grip and fall with immersive audio and controller rumble.

---

## 🕹️ VR Controls

| Action        | Input (VR Controllers)      |
|---------------|-----------------------------|
| Grab Hold     | Grip button (L/R)           |
| Release       | Let go of Grip button       |
| Climb / Pull  | Move hands while gripping   |

> The game uses Unity’s XR Interaction Toolkit with continuous locomotion disabled for a climbing-only experience.

## 🛠️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/vr-mountain-climber.git
```

### 2. Open in Unity
- Use Unity 2021.3+ LTS or newer
- Load the project via Unity Hub
- Install dependencies (via Package Manager):
- XR Plugin Management
- XR Interaction Toolkit
- Input System

### 3. Configure XR
- Open Edit > Project Settings > XR Plugin Management
- Choose your target platform (e.g., Oculus, OpenXR)
- Set up XR rig in the main scene (already configured in the project)

### 4. Play in VR
- Connect your VR headset (Quest via Link, Vive, etc.)
- Press Play in Unity or build the project for PC VR
